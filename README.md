# Still Funny? Language Models, Jokes, and Shifting Social Norms

Research code for "Still Funny?", which asks to what extent language models' generation and perception
of humor reflect changes in social norms over time.

- `exp0/`: the Exp. 0 pilot (7 models: GPT-3.5 Turbo, GPT-4o mini, GPT-6 Luna, Llama 2 7B, Llama 3.1 8B,
  Qwen2.5 7B, Qwen3 8B). Setup and run guide: [exp0/README.md](exp0/README.md). Labeling guide:
  [exp0/LABEL_GUIDE.md](exp0/LABEL_GUIDE.md).

Content warning: the experiments elicit and rate jokes, some of which rely on stereotypes. Raw model
outputs and the HaHackathon jokes (Meaney et al., 2021) are deliberately not in this repository;
only code, prompts and numbers-only summaries are.
